# Asset Replacement Guide

All visuals and audio in the prototype are **original placeholders**. The
architecture lets you swap in legally obtained or self-made assets without
touching gameplay code.

## Digimon models

Each species is a `DigimonSpecies` resource in `res://data/digimon/<id>.tres`.

| Field | Purpose |
|---|---|
| `model_path` | Path to a `.tscn`, `.scn`, `.glb` or `.gltf`. **Empty = procedural placeholder.** |
| `model_scale` | Uniform scale applied to the model root |
| `icon_path` | Optional portrait/icon texture |
| `animation_set` | Name of the animation contract (currently `creature_default`) |
| `sounds` | `{ "cry": "cry_roar" }` – sound ids resolved by AudioManager |
| `hovers` | Flying creatures float above the ground |

`DigimonVisual` (`res://digimon/digimon_visual.gd`) instances `model_path` and
searches the scene for an `AnimationPlayer`. The **creature animation
contract** is:

| Clip | Used for | Loop |
|---|---|---|
| `idle` | standing, menus | yes |
| `walk` | following / wandering | yes |
| `run` | catching up | yes |
| `attack` | physical skills | no |
| `skill` | special / support skills | no |
| `hurt` | taking damage | no |
| `defeat` | fainting (holds last frame) | no |
| `victory` | celebrating | yes |

Missing clips fall back gracefully (`run → walk → idle`, `skill → attack`, …).
Models should face **+Z** and have their origin at the feet.

Placeholder look is controlled by `placeholder_body` (`dino`, `big_dino`,
`beast`, `winged`, `wolf`, `angel`, `larva`, `goblin`, `plant`, `critter`,
`bird`, `blob`), `placeholder_colors` and `placeholder_options`.

## Player & NPC characters

`ChibiAvatar` (`res://characters/player/chibi_avatar.gd`) builds the human from
primitives using a `CharacterAppearance`. To use real models:

1. Create a scene per body type (or one rig with swappable meshes) that exposes
   `apply_appearance(appearance: CharacterAppearance)` and
   `play_animation(name: StringName, blend := 0.2)` / `play_once(name, then)`.
2. Implement the **humanoid animation contract**: `idle`, `walk`, `run`,
   `interact`, `battle_idle`, `attack`, `hurt`, `victory` (+ optional `wave`).
3. Replace the `Avatar` node in `res://characters/player/player.tscn` and the
   `ChibiAvatar.new()` calls in `Npc`, `BattleScene` and the new-game screens
   (search for `ChibiAvatar`).

Customization options are data in
`res://data/config/customization_catalog.tres` (body types with proportion
parameters, hairstyles, faces, tops, bottoms, shoes, accessories and colour
palettes). Adding a body type is adding an entry with its proportions.

## Icons

* Items: `res://assets/icons/items/<item_id>.svg` (referenced by
  `ItemData.icon_path`; PNG works too).
* UI: `res://assets/icons/ui/*.svg`.
* Regenerate placeholder item icons: `python3 tools/generate_item_icons.py`.

## Audio

`AudioManager` resolves sounds **by id and folder**:

* SFX: `res://audio/sfx/<id>.ogg` (or `.wav`, `.mp3`)
* Music: `res://audio/music/<id>.ogg` (or `.wav`, `.mp3`)

Drop a file with the same id to replace a placeholder. Music ids: `title`,
`field`, `forest`, `battle`, `victory`, `defeat` (maps choose music via
`MapData.music_id`). Enable *Loop* in the import dock for music. SFX ids used by
the game are listed in `tools/generate_placeholder_audio.py`.

Regenerate placeholders: `python3 tools/generate_placeholder_audio.py`.

## Fonts & theme

The UI theme (`res://ui/theme/game_theme.tres`) is generated by
`tools/generate_theme.gd` from `UIPalette` colours and the fonts in
`res://ui/theme/fonts/`. Swap `assets/fonts/*.ttf` or edit the font resources.

## World

Zone scenery is procedural (`StarterZoneBuilder`, `DataForestBuilder`, both
on `ZoneBuilderBase`). Gameplay objects (NPCs, pickups, triggers, spawners,
portals, spawn points) are regular nodes in `maps/<zone>/<zone>.tscn` and can
be moved in the editor.
To use hand-made art, replace the `Builder` node with your own scene (keep a
`get_height(x, z)` method or remove the ground-snap group from objects) and
keep static colliders under `NavigationRegion3D` so the navmesh bakes.
